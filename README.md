# Toto-ovociti di cbes

Mini sito statico per raccogliere le scommesse sul prossimo pick-up, ispirato al sito della festa di laurea.

## Pubblicazione

Il sito non richiede build: basta pubblicare i file nella root di GitHub Pages.

Il modulo invia le risposte allo stesso endpoint Formspree già usato nel sito della laurea.
